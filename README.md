# RedMatic-Matter

> Node-RED nodes that expose Homematic devices and arbitrary Node-RED data as
> a **Matter bridge**, built on [matter.js](https://github.com/matter-js/matter.js).
> The Matter sibling of [RedMatic-HomeKit](https://github.com/rdmtc/RedMatic-HomeKit),
> made for [RedMatic](https://github.com/rdmtc/RedMatic) on the CCU3 / OpenCCU.

**This is a placeholder release that reserves the package name. It contains
no nodes yet.** The plan lives in
[ROADMAP.md](https://github.com/rdmtc/RedMatic-Matter/blob/master/ROADMAP.md).
